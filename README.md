## What it does

`main.py` (Python 3, standard library only, no network) writes
one museum placard to `/output/entry.txt` — an ordinary office
lanyard labelled as if it were an ancient artifact:

> Lanyard, c. 2019, woven nylon, gift of Human Resources — worn daily for six years by a man whose name nobody in the building ever learned.

The line is 138 characters long. The placard reads like a real
museum label — catalogue date, material, donor — and the whole
joke is the twist packed into the final words: six years of daily
wear, and nobody in the building ever learned the wearer's name.
One line, one twist at the end.

## How to run

```sh
python3 main.py
```

## Output

Writes one placard (138 characters) to `/output/entry.txt`.
Running it twice produces byte-identical output.
